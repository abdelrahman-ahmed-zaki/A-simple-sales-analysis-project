# 📊 E-Commerce Sales Performance Analysis (SQL & Power BI)

## 📌 Project Overview
This project delivers an end-to-end analysis of e-commerce electronics sales across major Egyptian cities. Data was prepared, aggregated, and modeled in **SQL Server** using a dedicated database view (`vw_Sales_Dashboard`), then connected to **Power BI** to build an interactive executive dashboard.

## 🛠️ Tools & Technologies
* **SQL Server:** Data cleaning, transformation, and creation of the `vw_Sales_Dashboard` analytical view.
* **Power BI:** Data modeling, KPI cards, and interactive visualizations.

## 📈 Key Performance Indicators (KPIs)
* **Total Sales:** 142.98M
* **Net Profit:** 12.70M
* **Total Orders:** 2,683 Orders
* **Total Quantity Sold:** 7,000 Units

## 🔍 Key Insights
* **Top Performing Cities:** Aswan leads total sales and order volume, followed by Zagazig, Luxor, and Sohag.
* **Best-Selling Products:** High-end laptops and flagship smartphones dominate revenue, led by the **Asus ROG Strix G16**, **Lenovo ThinkPad X1**, and **iPhone 15 Pro Max**.
